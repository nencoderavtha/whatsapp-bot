WhatsApp AI Bot — System Architecture & Guardrails

Simplified Module Flow & Security Guardrail Overview

📱

1. Entry Points & Inbound Traffic

💬 Meta WhatsApp Cloud API

Receives customer text, voice notes, location pins, and interactive button clicks via Webhooks.

🛠️ Admin Management Portal

Express.js dashboard for order monitoring, kitchen dispatch, and manual rider calls.

↓
🛡️

2. Guardrails & Security Layer (Shield)

🔐 HMAC-SHA256 Verification

Validates x-hub-signature-256 on Meta webhooks to reject spoofed requests.

🛑 Express & User Rate Limiter

Enforces IP rate limits & sliding window 15 msgs/3min per phone to block spam.

🔍 Prompt Injection Guardrail

Scans customer text for jailbreak patterns ("ignore rules") & neutralizes override attempts.

↓
⚙️

3. Core Application Modules

🔄 Session Manager & Turn Locks

Manages conversation states & serializes rapid user messages into a single turn.

⚡ Fast-Path Pre-Parsers

Instant regex execution for commands ("menu", "cart") and explicit allergy warnings.

🚚 Shiprocket Delivery Orchestrator

Fetches quotes & dispatches 2-wheeler hyperlocal riders via Shiprocket Quick API.

↓
🧠

4. Resilient AI Engine (Multi-Provider Fallback Chain)

Guarantees 99.99% LLM uptime. If the primary provider experiences an outage, it automatically fails over:

OpenRouter ➔ Groq ➔ Cerebras ➔ Gemini
↓
🗄️

5. Data & Infrastructure Layer

🐘 Supabase PostgreSQL

Primary database storing orders, menus, customer profiles, and dispatch history.

⚡ Upstash Redis

Sub-millisecond turn locking, message queues, and delivery fee rate caching.

🔌 MCP Delivery Server

Model Context Protocol server exposing delivery tools for AI logistics.
